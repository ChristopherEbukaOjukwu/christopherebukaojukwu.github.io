# Christopher Ebuka Ojukwu — personal website

A minimalist six-page website designed for GitHub Pages and the domain `christopherojukwu.com`.

## Pages

- `index.html` — Home
- `about.html` — About, education, experience
- `research.html` — Research, publications, selected talks
- `teaching.html` — Teaching and mentorship
- `cv.html` — CV download
- `contact.html` — Contact

## Publish to your EXISTING GitHub Pages repository

Repository: https://github.com/ChristopherEbukaOjukwu/christopherebukaojukwu.github.io

1. Keep a backup of the repository before replacing any files.
2. Upload the contents of this folder (not the enclosing folder) to the root of the existing repository, on the branch used by GitHub Pages.
3. Keep the existing root-level `christoper.JPEG` portrait file in the repository. This ZIP intentionally does **not** duplicate your existing photograph. The homepage uses that existing filename.
4. This project includes the existing approved custom-domain `CNAME` value. Do not delete it.
5. Wait for GitHub Pages to deploy, then check https://christopherojukwu.com/.

No frameworks, build steps, JavaScript, payment, or hosting plan needed. The downloadable CV PDF is included under `assets/`.

## Editing

Open the relevant HTML page in a text editor. Research and publication entries are in `research.html`, and talks are listed at the bottom of the same page. Add a link to a talk's slides only after uploading that PDF to your repo (e.g., `assets/talks/my-talk.pdf`), avoiding dead links. Shared styles are in `assets/styles.css`.

## Google indexing

The website contains descriptive titles, canonical URLs, Person structured data, `robots.txt`, and `sitemap.xml`. After the site is live, submit `https://christopherojukwu.com/sitemap.xml` in Google Search Console. Search rankings cannot be guaranteed.
